# 刷B站 · 竖滑视频流

把 B 站变成**可以上下滑的沉浸式竖屏视频流**：一个视频一屏，手指一滑换一个，右侧点赞/投币/收藏/评论，
双击点赞、长按菜单、静音启动、自动连播——还原手机刷短视频的手感，但内容全部是 B 站的。

这是一个 Chrome / Edge 扩展（Manifest V3），**直接复用你在 bilibili.com 已登录的账号**，
不需要扫码、不需要填 Cookie、不经过任何第三方服务器。

```
上下滑 / 滚轮 / ↑↓   →  换视频        单击  →  暂停 / 播放
双击中间              →  点赞（飘心）  双击左右 →  快退 / 快进 10 秒
长按                  →  更多菜单      长按上拖 →  倍速播放
空格 播放暂停   L 点赞   C 评论   F 收藏   M 静音   S 设置   R 换一批   Esc 退出
```

## 一、安装（30 秒）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本仓库的 **`extension/`** 目录
4. 打开任意 B 站页面

装好后**入口就在 B 站自己的界面里**，不需要去找插件按钮：

| 位置 | 说明 |
| --- | --- |
| **顶栏右侧**（头像左边） | 一颗粉色「竖滑刷」药丸，和站内自己的入口排在同一行，所有 B 站页面都有 |
| **视频页「一键三连」那一排末尾** | 点一下直接在当前这个视频上开刷（会把当前视频插到队首先播） |
| 工具栏扩展图标 / 快捷键 | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> 或 <kbd>\\</kbd>（反斜杠键） |

入口位置可以换：设置面板 → 入口 → `嵌进顶栏` / `右下角悬浮按钮` / `只要快捷键`。
若 B 站改版导致顶栏锚点找不到，插件会**自动退回右下角悬浮按钮**，不会没有入口。

> 想改快捷键：`chrome://extensions/shortcuts`

## 二、播放原理（为什么手感能做得这么跟手）

播放层是**双引擎**，自动选择、失败自动降级：

| 引擎 | 何时使用 | 能力 |
| --- | --- | --- |
| **原生 `<video>`**（默认） | 通过 `playurl` 拿到「带声音的整段 MP4」直链时 | 单击暂停、拖拽 seek、自绘进度条、倍速、静音/音量、单条循环、自绘弹幕——**全部自己控制**，所以手势能做到抖音那种跟手程度 |
| **官方 iframe 播放器**（兜底） | 番剧/付费内容、接口风控、直链 403、重新签名仍失败 | 官方外链播放器只开放 URL 参数（`autoplay`/`muted`/`danmaku`/`t`/`poster`），没有 JS API，所以这个模式下点击交给官方控件，其余手势照常 |

图片裁切用 `object-fit: cover` 做成竖屏满屏（设置里可切「铺满 / 完整显示」）。

## 三、内容来源

顶栏一键切换，全部走 B 站官方 Web 接口：

| 来源 | 接口 | 说明 |
| --- | --- | --- |
| **推荐** | `wbi/index/top/feed/rcmd` | 首页推荐流，**需要 WBI 签名**（`api.js` 里用纯 JS 实现了官方 MD5 + mixin key 算法，密钥从 `nav` 接口实时取） |
| **热门** | `web-interface/popular` | 综合热门 |
| **排行榜** | `web-interface/ranking/v2` | 分区轮换（全站→动画→音乐→游戏…），保证刷不完 |
| **关注** | `polymer/web-dynamic/v1/feed/all` | 关注动态里的视频投稿 |

队列会**去重**（本地记录最近刷过的）、**过滤已屏蔽的**、**自动补货**；任何接口挂了都会退到热门，
推荐接口连续失败还会提示你，做到「永远有的刷」。

## 四、支持的交互

**刷**
- 上下滑动 / 滚轮 / <kbd>↑</kbd><kbd>↓</kbd> / <kbd>J</kbd><kbd>K</kbd> / 空格 切换
- 上滑下一屏时，当前页缩放回落、相邻页缩放进场（抖音同款层次感）
- 回退到上一条、回到第一条都有提示
- 预加载：提前取好下一条的 `cid` 和播放地址，滑过去立刻出画面

**看**
- 单击暂停/播放（中间弹大图标），双击左右两侧 ±10 秒
- 自绘进度条，可点可拖 seek，右下角显示 `当前 / 总时长`
- 自绘弹幕（XML 接口 + 轨道动画），设置里可开关
- 长按上拖 = 2x/3x 倍速，松手恢复
- 单条循环 / 自动连播 / 静音启动（受浏览器自动播放策略影响，默认静音起步）
- 画面填充三档：竖屏裁切 / 铺满 / 完整显示

**互动**（右侧竖排，和手机端一致）
- 点赞（双击也能赞，带飘心动画）、投币 2 枚、收藏到默认收藏夹、评论、分享
- 未登录时自动唤起站内登录弹窗，不会静默失败
- 关注 / 取关 UP 主
- 长按菜单：不感兴趣、稍后再看、倍速、复制链接、在 B 站打开、只看这个 UP 主
- 评论抽屉：分页加载、楼层回复、IP 属地、点赞数

**入口**
- 顶栏药丸：插在 B 站顶栏头像左边，和站内入口同一排，所有页面可见
- 视频页互动栏按钮：点一下就在当前视频上开刷
- 悬浮按钮兜底：顶栏改版/锚点找不到时自动顶上
- 入口位置三档可切，`Alt`+<kbd>Shift</kbd>+<kbd>B</kbd> / <kbd>\\</kbd> 快捷键随时可用

**其他**
- 设置面板：内容来源、入口位置、自动连播、循环、静音启动、弹幕、画面填充、预取条数、清晰度、本地屏蔽列表管理
- 打开时隐藏原页面（可关），`Esc` 逐层退出（抽屉 → 面板 → 视频流）
- 键盘全操作，鼠标/触屏/触控板都能用

## 五、目录结构

```
extension/                 扩展本体（加载这个目录）
├─ manifest.json
├─ icons/                  图标（由 tools/gen-icons.mjs 用纯代码生成）
├─ popup/                  工具栏弹窗：开关 + 常用设置
└─ src/
   ├─ core.js              命名空间与工具（DOM/格式化/存储/节流）
   ├─ config.js            设置 + 本地屏蔽 + 已看过去重（chrome.storage.sync）
   ├─ api.js               B 站接口封装：WBI 签名、卡片归一化、BV/av 互转、互动 POST
   ├─ feed.js              视频流队列：多来源、去重、预取、自动补货、降级
   ├─ icons.js             内联 SVG 图标集
   ├─ entry.js             把入口嵌进 B 站界面（顶栏药丸 / 视频页互动栏 / 悬浮兜底）
   ├─ styles.css           全部样式（bbdy- 前缀，不污染 B 站页面）
   ├─ content.js           入口：设置引导、消息通道、快捷键
   ├─ background.js        Service Worker：图标/快捷键 → 内容脚本
   └─ ui/
      ├─ player.js         双引擎播放器 + 自绘弹幕
      ├─ overlay.js        全屏竖滑容器：三槽循环、手势、键盘、互动编排
      ├─ actionbar.js      右侧互动栏
      ├─ comments.js       评论抽屉
      ├─ settings.js       设置面板 / 长按菜单 / 倍速菜单 / 帮助
      └─ sheets.js         底部抽屉、开关行、Toast 等基础组件

demo/                      离线演示台（不需要装扩展、不碰真实账号）
test/api.test.mjs          接口与算法自测（MD5/WBI/BV-av 等）
test/entry.test.mjs        入口注入自测（插入位置、降级、重插）
tools/gen-icons.mjs        纯代码生成 PNG 图标
tools/build-release.mjs    零依赖 ZIP 打包
```

## 六、本地演示（推荐先玩这个）

不需要装扩展，也不需要登录，用假数据把整套交互跑通：

```bash
node demo/demo-server.mjs          # 默认 http://127.0.0.1:8788
```

浏览器打开 <http://127.0.0.1:8788/>，会自动进入竖滑视频流。

演示服务做三件事：
1. 原样托管 `demo/index.html` 与 `extension/src/*`（**demo 页面跑的就是扩展的同一份代码**，只换了两个"插座"：接口地址与播放地址）
2. 在 `/mock/*` 上假装成 `api.bilibili.com`，返回结构与真实接口一致的假数据（推荐/热门/排行/关注/评论/playurl/点赞投币收藏关注）
3. 自己现搓一个 30 秒的合法 MP4 当视频直链，并支持 Range 请求

## 八、已知边界

- **清晰度**：外链播放器与未登录的 `playurl` 通常只给到 480P/720P；登录后会更好。设置里的清晰度选项在原生引擎下会重新拉流。
- **iframe 兜底模式**：官方外链播放器**没有公开的 JS 控制接口**（URL 参数之外都不可控），所以该模式下暂停/倍速/进度由官方控件负责，我们只做手势与信息层。代码里仍保留了 `postMessage` 通道并在 `BBDY.debug = true` 时打印回包，方便日后官方开放接口时接入。
- **自动播放**：浏览器要求用户手势才能出声，所以默认静音启动，点一下画面或按 <kbd>M</kbd> 开启声音。
- **不感兴趣 / 收藏**：走的是 B 站自己的接口，行为与网页端一致；「不感兴趣」同时会在本地把该视频从队列移除。
- **入口依赖 B 站的 class 名**（`.right-entry__main`、`#arc_toolbar_report` 等）。这些名字是从线上页面里确认过的，但 B 站改版后可能失效；失效时插件会**自动退回右下角悬浮按钮**，不会没有入口，也可以在设置里手动固定入口位置。
- 本项目只读写 B 站自己的域名（`*.bilibili.com` / `*.hdslb.com`），**不向任何第三方服务器发送数据**。
